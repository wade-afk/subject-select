학교를 선택하세요

학교를 고르면 그 학교 교육과정 편성표대로 선택과목이 나옵니다.

선생님용 미리보기 화면입니다. 학생 제출은 맨 아래 선생님용에서 만든 학생용 링크로만 받을 수 있어요.

내 정보

현재 학년을 고르면 내년에 배울 선택과목이 나옵니다.

선생님용 · 구글 시트 연결하고 학생용 링크 만들기
  1. 결과를 모을 구글 스프레드시트를 새로 만들고, 메뉴 확장 프로그램 → Apps Script를 엽니다.
  2. 편집기의 기본 코드를 지우고 한 코드를 붙여넣은 뒤 저장합니다.
  3. 배포 → 새 배포 → 웹 앱 (실행: 나 / 액세스 권한: 모든 사용자) → 배포 후 나오는 웹 앱 URL을 복사합니다.
  4. 아래에 URL을 붙여넣고 [연결 확인]을 누르면 학생용 링크와 QR이 만들어집니다.
