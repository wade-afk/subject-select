# 과목 선택 페이지 (수요조사 수합용)

학교를 고르면 그 학교 교육과정 편성표대로 선택과목이 나오고, 학생이 고른 결과가 **선생님의 구글 스프레드시트**에 쌓이는 가벼운 페이지입니다.
[2026 교육과정 박람회](https://github.com/wade-afk/2026-curriculum-fair) 사이트에서 과목 선택·제출 기능만 떼어 냈습니다.

| 파일 | 설명 |
|---|---|
| `index.html` | 페이지 본체 (학교 선택 · 과목 선택 · 제출 · 선생님용 링크 만들기) |
| `Code.gs` | 구글 시트에 붙이는 수합용 앱스크립트 |

학교 목록(`schools.json`)과 편성표 엑셀(`schools/*.xlsx`)은 박람회 사이트의 것을 그대로 읽어 옵니다.
다른 곳의 자료를 쓰려면 `index.html` 위쪽 `DATA_BASE` 주소만 바꾸면 됩니다.

## 올리기

두 파일을 깃허브 저장소에 올리고 **Settings → Pages → Deploy from a branch (main / root)** 를 켜면 됩니다.
새 저장소를 만들어도 되고, 박람회 저장소 안에 `select/` 같은 폴더로 넣어도 됩니다.

## 선생님이 할 일 (학교당 1회, 약 5분)

1. 페이지에서 **우리 학교 선택** → 편성표대로 선택과목이 맞게 나오는지 확인합니다.
2. 결과를 모을 **구글 스프레드시트**를 새로 만들고 **확장 프로그램 → Apps Script** 를 엽니다.
3. 페이지 맨 아래 **선생님용** 을 펼쳐 **[수합 코드 복사]** → 편집기의 기본 코드를 지우고 붙여넣기 → 저장.
4. **배포 → 새 배포 → 유형: 웹 앱** / 실행: **나** / 액세스 권한: **모든 사용자** → 배포 → **웹 앱 URL** 복사.
   (처음에는 권한 승인 창이 뜹니다. "확인되지 않은 앱" 경고가 나오면 고급 → 이동.)
5. 페이지의 선생님용 칸에 URL을 붙여넣고 **[연결 확인]** → **학생용 링크와 QR** 이 만들어집니다.
6. 학생에게는 이 **학생용 링크(QR)** 만 안내합니다. 이 링크는 우리 학교로 고정되고, 제출은 우리 시트로만 들어갑니다.

> 코드를 고친 뒤에는 **배포 관리 → ✏ → 버전: 새 버전 → 배포** 를 해야 반영됩니다. URL은 그대로입니다.

## 학생 화면

현재 학년 선택 → 반·번호·이름 입력 → 묶음마다 정해진 수만큼 선택 → 제출.

- **현재 1학년**은 가장 최근 입학생 편성표의 **2학년** 과목을, **현재 2학년**은 그 전 입학생 편성표의 **3학년** 과목을 고릅니다.
- 같은 학번으로 다시 제출하면 이전 제출을 덮어씁니다.

## 시트에 쌓이는 모양

- **`1학년` · `2학년` 탭** (현재 학년 기준): 학생 1명이 1줄. 1행 학기 / 2행 선택 묶음(택N) / 3행 과목명, 고른 과목 칸에 `1`.
  아무도 고르지 않은 과목도 열로 만들어집니다.
- **`집계` 탭**: 학년 · 학기 · 선택 묶음 · 과목 · 신청 인원. 제출될 때마다 다시 계산됩니다.
  줄을 직접 지우거나 고쳤다면 메뉴 **📋 과목 선택 → 집계 새로고침**.
- 1~3행 머리글은 고치지 마세요. 스크립트가 머리글로 열을 찾습니다.

## 편성표를 읽는 규칙

학교알리미 「재학생의 3개년 교육과정 편성표」 엑셀의 입학생 시트에서 `학생 선택` 구역을 묶음 단위로 읽습니다.

- 묶음에서 고를 과목 수 = 학기 학점 ÷ 운영학점. 나눠떨어지지 않으면 `택N` 을 따릅니다.
- 고를 수가 과목 수 이상인 묶음(음악·미술 교차 수강 등)은 고를 것이 없으므로 "모두 함께 배우는 과목"에 넣습니다.
- 과목명에 `순증` 이 들어간 묶음은 **희망자만** 고르는 묶음으로, 비워 두어도 제출됩니다.
- 같은 과목은 다른 묶음·다른 학기에서 다시 고를 수 없습니다.

편성표가 실제 수요조사 방식과 다르게 적혀 있으면 화면도 다르게 나옵니다. 배포 전에 1번 단계에서 꼭 확인하세요.

## 유의

- 학번·이름·선택 과목은 선생님이 연결한 구글 시트에만 저장됩니다.
- 본인 확인 절차는 없습니다. 다른 학생의 반·번호로 제출하면 그 줄이 덮어써지므로, 마감 후 시트를 확인하세요.
