# 과목 선택 체크리스트 (단독 사이트)

[2026 교육과정 박람회](https://github.com/wade-afk/2026-curriculum-fair) 사이트의 **과목 선택 체크리스트 페이지만** 떼어 낸 사이트입니다.
화면과 기능은 박람회 사이트의 체크리스트와 같습니다.

- PC: 한눈에 보기(3년 설계표 보드). 상단에 학교 이름 · [더 알아보기] · 다른 학교 검색창
- 모바일(너비 768px 이하): 세로로 스크롤하며 고르는 단계별 화면 — 묶음마다 과목 버튼이 나오고, 다 고른 묶음은 고른 과목만 또렷하고 나머지는 흐려짐. 위 묶음을 다 골라야 다음 묶음이 열리고, 마지막에 확인 후 제출.
- 학교 선택(이름 검색, 지역 › 구·군 › 학교), 학교 전용 주소(잠금 링크)
- 희망 계열 ⭐ · 목표 대학 핵심/권장 표시 · 충족표 · 추천으로 빈칸 채우기
- 과목 설명 팝업(ⓘ) · 졸업 요건 · 상담 리포트 인쇄
- 결과 제출(구글 시트 수합) · 선생님용 결과 수집 신청

박람회 사이트의 다른 페이지(홈·교과별 과목 안내·대학별/계열별 권장과목·영상·2028 대입·관리자 설정)는 넣지 않았습니다.
체크리스트 아래 "더 알아보기" 링크는 박람회 사이트의 해당 페이지를 새 탭으로 엽니다.

## 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 체크리스트 페이지 본체 |
| `school-config.js` | 기본 학교(작전고) 설정 — 박람회 저장소의 것과 같음 |
| `404.html` · `s/` | 학교 전용 짧은 주소(`…/s/학교id/`) 처리 |

## 박람회 사이트와 함께 쓰는 것

- **학교 목록·편성표 엑셀**: 박람회 사이트의 `schools.json` 과 `schools/*.xlsx` 를 그대로 읽어 옵니다.
  학교를 추가하거나 엑셀을 바꿀 때는 박람회 저장소만 고치면 됩니다. (`index.html` 의 `DATA_BASE`)
- **결과 수집**: 박람회 사이트와 같은 운영자 앱스크립트로 접수합니다. 승인된 학교만 제출할 수 있고,
  학교 시트·승인 절차는 박람회 저장소의 `operator-script/` 안내와 같습니다.

## 학교 전용 주소

- `https://wade-afk.github.io/subject-select/s/<학교id>/` → 그 학교로 고정된(잠긴) 주소
- 같은 주소: `…/subject-select/?school=<학교id>&lock=1`
- 결과 제출은 학교 전용 주소로 들어온 경우에만 받습니다.

운영자 앱스크립트의 승인 메일·QR은 `CONFIG.SITE_URL` 주소로 만들어집니다.
이 사이트 주소로 안내하려면 그 값을 `https://wade-afk.github.io/subject-select/` 로 바꾸고 새 버전으로 배포하세요.
